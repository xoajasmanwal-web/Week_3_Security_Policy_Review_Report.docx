# Enterprise Security Policy Review & Gap Analysis — Week 3 Task

## Overview
This repository contains a comprehensive review and gap analysis of a hypothetical organization's Information Security Policy (ApexTech Corp), evaluated against NIST CSF 2.0, ISO/IEC 27001:2022, and NIST SP 800-63B.

## Key Areas Covered
- **Critique & Weaknesses:** Outdated password rotation rules, optional MFA, missing data classification, unmanaged Shadow IT/AI, undefined patching SLAs, and lack of vendor vetting.
- **Recommendations:** Phishing-resistant MFA (FIDO2/passkeys), 4-tier data classification with AES-256/TLS 1.3 encryption, Acceptable AI & SaaS Use Policy, strict patching SLAs (48h for Critical), and Third-Party Risk Management (TPRM).
- **Implementation Roadmap:** 90-day phased rollout (Immediate, Short-Term, and Medium-Term) with formal policy governance and exception handling.
